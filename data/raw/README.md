# Directory: data/raw

This directory contains raw data used for customer segmentation through the Data Fabric approach. Raw data refers to unprocessed data that hasn't been cleaned, transformed, or aggregated. The customer segmentation process uses this data to derive meaningful insights about customer behavior and characteristics, which can then inform marketing strategies, product development, and customer service initiatives.

Files in this directory should be stored in their original format and structure to maintain data integrity, allowing for accurate analysis and reporting later on.
